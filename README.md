# Shopify Web Development Assignment

Shopify implementation of the provided Figma designs using Liquid, CSS and vanilla JavaScript.

## Sections

- Hero Slider
- Drop Teaser
- Display Text
- Product Grid
- Reusable Product Card

## Highlights

- Shopify Online Store 2.0 sections
- Fully configurable from Theme Editor
- Responsive layouts
- Vanilla JavaScript interactions
- Real Shopify product and variant data
- Product colour/variant switching
- Quick Add with cart updates
- Countdown timer
- Shopify newsletter form
- No jQuery or page builder

### Countdown Note

The Figma shows Days, Hours and Seconds. I added Minutes to make the countdown more practical:

`Days : Hours : Minutes : Seconds`
